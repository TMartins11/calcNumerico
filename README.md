# Cálculo Numérico

Bem-vindo ao repositório de Cálculo Numérico! Este repositório reúne os trabalhos práticos desenvolvidos ao longo da disciplina, implementando métodos numéricos em Python.

## 🏗️ Estrutura do Repositório

### 📊 [trabalhos](https://github.com/TMartins11/calcNumerico/tree/main/trabalhos)
Trabalhos práticos da disciplina, um por tópico, cada um com código-fonte, enunciado (`trabalho.pdf`) e relatório final:

- **trabalho_metodos_diretos** — sistemas lineares (Gauss, LU, Cholesky, Thomas, número de condição, PageRank).
- **trabalho_metodos_interativos** — métodos iterativos (Jacobi, Gauss-Seidel, SOR, gradiente conjugado, análise de convergência e custo).
- **trabalho_interpolacao_ajuste_curvas** — interpolação e ajuste de curvas.
- **trabalho_derivacao_integracao_numerica** — derivação e integração numérica.

Cada trabalho é executado a partir do seu `main.py` (ex.: `python main.py`).

## 🎯 Objetivo do Repositório

Este repositório documenta a implementação prática dos principais métodos numéricos estudados na disciplina.
